# Skills

A collection of [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) for Claude, built with a repeatable, eval-first workflow.

## Install

**Claude Code (plugin marketplace):**

```
/plugin marketplace add Jay-Mehta/Skills
/plugin install skills@jay-mehta-skills
```

**Single skill:** copy (or symlink) a folder from `skills/` into `~/.claude/skills/` (personal) or `.claude/skills/` (project). For claude.ai, zip the skill folder and upload it under Settings → Capabilities.

Only skills in `skills/` are published. Anything in `under-construction/` is work in progress and is not installed by the marketplace.

## Repository layout

```
├── skills/               Ready skills: published via the marketplace
├── under-construction/   Skills in development: not published
├── scripts/
│   ├── new-skill.sh      Start a new skill in under-construction/
│   ├── validate.py       Structural + stage checks (run by CI)
│   ├── promote.sh        Move a reviewed skill into skills/
│   └── sync_index.py     Regenerate this README's index and marketplace.json
├── requirements.txt      Python deps for the scripts (PyYAML)
├── .claude-plugin/marketplace.json
└── .github/              PR template (promotion checklist) and CI
```

Each skill folder contains:

| File | Purpose |
|---|---|
| `SKILL.md` | The skill: YAML frontmatter (`name`, `description`) plus instructions |
| `BRIEF.md` | Why the skill exists: problem, users, triggers, scope, success criteria |
| `STATUS.md` | Current lifecycle stage and a decision log |
| `evals/evals.json` | Test prompts, including ones that should *not* trigger the skill |
| `evals/results.md` | The latest eval run and its overall result |
| `scripts/`, `references/`, `assets/` | Optional: helper code, docs loaded on demand, output templates |

## Creating a skill

Read [CONTRIBUTING.md](CONTRIBUTING.md). In short:

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # once
source .venv/bin/activate

./scripts/new-skill.sh my-skill      # 1. Propose  → fill in BRIEF.md
                                     # 2. Design   → write evals/evals.json
                                     # 3. Draft    → write SKILL.md
                                     # 4. Test     → run evals, record evals/results.md
./scripts/promote.sh my-skill        # 5. Review   → moves it to skills/, open a PR
                                     # 6. Ready    → merge
python3 scripts/validate.py          # run anytime; CI runs it on every PR
```
